# 打卡状态（daka-status）

一个监控**企业微信上下班打卡状态**的 Android 小工具：桌面小组件实时显示今天上班/下班是否已打卡、打卡时间，到点未打卡时用**闹钟级提醒**叫你去打卡。本地运行、静默读取，**不做自动打卡**。

> 适配**企业微信 Android 4.1.27**（打卡页组件名为硬编码，企微大版本改版可能导致读取失败，届时 App 会显示具体错误信息）。

## 功能

- **桌面小组件**：显示当日打卡状态（上班/下班已打时间或未打）、数据更新时间戳；超过 26 小时未更新显示"已过期"
- **闹钟级提醒**：上班前、下班后到点未打卡时，`AlarmManager.setAlarmClock` 精确闹钟全屏弹出 + 铃声 + 震动（Doze/省电策略下不延迟）；响铃由独立前台服务播放，最多 2 分钟，可点通知"停止响铃"
- **两组班次时间**：上班时间、下班时间独立设置；提醒间隔（提前/延后分钟数）统一可调
- **法定节假日判断**：工作日才安排提醒和刷新；节假日表从网络更新，离线时有内置表 + 周末规则兜底
- **每日自动刷新**：02:00–11:00 与 17:00–01:00 两个刷新窗口内按设定间隔自动读取；休息日不刷；亮屏时主动触发
- **日报入口**：一键打开企业微信"汇报"页查看日报是否已提交（企微汇报页无法静默读取，见已知限制）

## 工作原理

需要 **root**。App 通过三重机制静默获取打卡状态，不改变任何打卡行为：

1. **虚拟屏 + 无障碍**：在系统虚拟显示屏（`display no decorations`）上静默打开企业微信打卡页，用无障碍服务读取页面节点解析状态；全程企微不会弹到前台
2. **本地考勤数据库直读**（优先）：通过 root 在虚拟屏进入"打卡 → 统计"让企微刷新本地明细，复制 `attendance.db`（wxSQLite3 AES128 加密，解码算法见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)）到本应用缓存中解码，校验账号/日期/班次/时间后采用；数据库结果优先于页面文字
3. **节假日表**：从网络下载法定节假日 JSON（格式 `{"YYYY-MM-DD": 2|3}`，2=节日休息、3=调休补班），离线回退内置表

唯一的联网行为就是下载节假日表；打卡数据全部本地读取。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| Android | 8.0（API 26）及以上 |
| root | 必须（Magisk 即可，用于虚拟屏命令和读取企微数据） |
| 企业微信 | **4.1.27**（其他版本不保证） |
| 无障碍 | 需启用本应用的无障碍服务 |
| 精确闹钟 | 需授予"闹钟和提醒"/精确闹钟权限（SCHEDULE_EXACT_ALARM） |
| 其他建议 | 系统设置中开启自启动、电池策略设为"不限制"，降低被杀停概率 |

## 安装

从 [Releases](../../releases) 下载 `daka-status.apk`：

```bash
adb -s <serial> install -r daka-status.apk

# install 会取消全部闹钟，装完必须重新武装（或打开一次 App）：
adb -s <serial> shell su -c "am broadcast -a android.intent.action.MY_PACKAGE_REPLACED -n com.daka.status/.BootReceiver -f 32"
```

安装后：

1. 打开 App，在系统设置里启用它的**无障碍服务**
2. 在设置页配置上班/下班时间与提醒间隔
3. 授予精确闹钟权限；部分系统还会询问通知/悬浮窗权限
4. 回到桌面添加"打卡状态"小组件

部分厂商系统会在更新或强停后关闭无障碍；更新后应在主页确认连接状态。

## 使用说明

- **主页**：显示当前打卡状态、无障碍连接状态、最近刷新结果与错误信息；可手动刷新、稍后提醒
- **设置页**：上班/下班时间、提醒间隔（同一间隔用于上班提前、下班延后）、自动刷新开关、刷新间隔
- **小组件**：时间戳当天显示 `HH:mm`，跨天显示 `M-d HH:mm`，超过 26 小时显示 `已过期 M-d`（即数据陈旧，去打开一次 App）
- **提醒弹窗**：全屏显示班次与状态，按钮"知道了"关闭；未打卡时可"稍后提醒"（按提醒间隔再延后一次）

## 运维注意（重要）

- **强停 = 闹钟全灭**：App 被"强行停止"（手动或系统省电策略）后，系统会同时清空全部闹钟（提醒、自动刷新、02:00 日切），且强停状态下收不到开机广播、重启也不自愈。**打开一次 App 即全部恢复**
- **无障碍被杀**：无障碍服务被 OEM 杀进程后会留在系统 `Crashed services` 里且不会自动重绑。App 每次刷新前和打开时用 root 重写无障碍开关强制重绑（5 分钟节流），无需手动处理；若主页持续显示未连接，手动去设置里重新开关一次
- **屏幕关闭/锁屏时**无法让企微刷新统计缓存，解锁后再读取；熄屏不会主动点亮或解锁手机
- **早卡时间**：企微打完下班卡后页面只显示最近一次（下班）时间；早卡时间只有在"早卡之后、晚卡之前"成功读取过一次才会保留显示
- **时间/时区变更**会自动重排全部闹钟

## 构建

无 Gradle，纯 aapt2 + javac + d8 + zipalign + apksigner 流水线：

```
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

- 需要 Android SDK build-tools 35 + android-35 platform + JBR（路径写在 build.ps1 顶部，按本机调整）
- 产物 `daka-status.apk`（versionCode = epoch 秒，versionName = 1.0.yyMMdd.HHmm）
- **签名密钥不入库**：首次构建时 build.ps1 会自动在本地生成新的 keystore；注意新密钥签名与已有安装不一致，无法覆盖安装，请保留你自己的 `daka.keystore` 并离线备份
