## 修复

1. 原排程将上下班时间均减去间隔，刷新补提醒也会在下班前触发。现在共用 ReminderTime：上班提前、下班延后。保留手机原设置 08:30 / 18:00、30 分钟，因此对应 08:00 / 18:30。
2. 持续响铃原先依赖 AlertActivity。现在由独立 mediaPlayback 前台服务承担播放和震动；不依赖弹窗启动成功。优先读取系统闹钟铃声，失败时回退内置 WAV。
3. 服务使用 USAGE_ALARM、音频焦点和播放唤醒锁；最多响铃 120 秒、震动 90 秒。停止提醒/通知操作释放播放资源，按条件恢复临时调整的闹钟音量。
4. 按班次所属工作日判断节假日，携带 workDate 到广播、去重和稍后提醒；跨午夜不按响铃的日历日期误判。
5. 设置说明改为“上班提前、下班延后”，通知不再显示错误的下班前倒计时。

主要改动：AlarmScheduler.java、AlarmReceiver.java、ReminderTime.java、Notifier.java、AlarmSoundService.java、AlertActivity.java、RefreshService.java、AndroidManifest.xml、activity_settings.xml、res/raw/reminder_alarm.wav，以及测试和 README。
